# Portfolio

Angela Ormond's portfolio: one page that introduces her work as a Senior Program Manager in AI and business operations, shows projects she has built, and walks through her experience. The tone is plain and team-focused, with results told inside the story of the work.

**View the page:** coming soon on GitHub Pages

Everything is in one `index.html` file with no build step, so it runs on GitHub Pages or any static host.

## What's on the page

| Section | What it covers |
| --- | --- |
| **Introduction** | A one-line headline, with **View my work** and **Get in touch** buttons |
| **What I do** | Program Management, AI Tools Integration and Process Automation |
| **About** | Who Angela is and the kind of problems she solves |
| **Selected work** | Projects she has built, with links |
| **Skills** | Tools and areas she works in |
| **Experience** | Roles at Microsoft (including Xbox Release Excellence) and Ansys |
| **What people say** | Short notes from colleagues |
| **Contact** | Email, LinkedIn and GitHub |

## Host it on GitHub Pages

Add `index.html` to this repository, then go to Settings → Pages, choose "Deploy from a branch", pick `main` and `/ (root)`, and save. The page will be at https://angelaor.github.io/Portfolio/ a minute or two later.
